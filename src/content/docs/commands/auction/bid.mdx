---
title: Auction bid
description: Bid for a Pokémon on auction
---

Using this command you can bid on a Pokémon that is listed on the auction.

# Command Usage

```
/auction bid \<auctionID\> \<amount\>
```

# Parameters

- `auctionID` (required): The unique ID of the auction you want to bid on.
- `amount` (required): The amount of credits you want to bid.

# Examples

- `/auction bid d9b 100`: bid 100 credits on auction with ID d9b
